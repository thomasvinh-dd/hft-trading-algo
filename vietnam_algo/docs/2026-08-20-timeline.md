## Live DNSE Execution Safety

### Initial Orderbook Pricing

Added initial orderbook pricing before submit:

```text
BUY  -> DNSE best ask
SELL -> DNSE best bid
```

Added max drift protection:

```text
BUY cannot chase above signal price + max drift
SELL cannot dump below signal price - max drift
```

Recommended live flags:

```bash
--initial-orderbook-pricing \
--max-price-drift-percent 2 \
--monitor \
--max-checks 3 \
--check-interval-seconds 5 \
--cancel-if-unfilled
```

### Sellable Quantity Cap

Added live DNSE sellable quantity cap:

```text
before real submit, fetch DNSE positions
SELL orders are capped to sellableQuantity / availableQuantity
quantity is rounded down to board lot
SELL is skipped when sellable quantity is zero
```

This applies to:

```text
normal strategy sell orders
corporate-action forced exits
```

### Monitor Exhaustion Warning

Added monitor event when order remains open after all reprice checks:

```text
monitor_exhausted_unfilled
```

If `--cancel-if-unfilled` is enabled:

```text
cancelled_unfilled
```

Telegram now warns:

```text
WARNING: unfilled orders after reprice limit
NB VCB qty=100 price=50,000 | status=UNFILLED_AFTER_REPRICE_LIMIT
```

Or:

```text
WARNING: unfilled orders after reprice limit
NB VCB qty=100 price=50,000 | status=CANCELLED_UNFILLED
```
